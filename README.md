# 🚀 Ethara.ai - MERN Task Management System

Ethara is a robust, full-stack task management application designed for teams and individual developers. It features a professional Kanban-style dashboard, real-time status tracking, and project-based team collaboration.

## ✨ Features

- **Authentication:** Secure Signup/Login using JWT (JSON Web Tokens).
- **Kanban Board:** Organize tasks into `Todo`, `In Progress`, and `Done` columns.
- **Project Management:** Create distinct workspaces and invite team members.
- **Task Assignment:** Assign specific tasks to project members with due dates.
- **Priority System:** Categorize tasks as High, Medium, or Low priority.
- **Analytics Dashboard:** Visual counters for Total, Overdue, and Completed tasks.
- **Responsive UI:** Clean, modern interface built with Tailwind CSS.

## 🛠️ Tech Stack

**Frontend:**
- React.js
- Tailwind CSS
- Axios (API Calls)
- React Router (Navigation)

**Backend:**
- Node.js
- Express.js
- MongoDB Atlas (Cloud Database)
- Mongoose (Object Modeling)
- JWT (Security)
